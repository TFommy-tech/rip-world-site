Политика конфиденциальности

Дата вступления в силу: 27.09.2026
Условия использования

1. Какие данные используются

Для работы функций Rip World приложение может обрабатывать Discord ID пользователя и связанные с ним игровые данные.

В зависимости от используемых функций могут храниться игровые профили, Каммы, яйца, питомцы, инвентарь, достижения, Battle Pass, статистика сообщений, статистика нахождения в голосовых каналах и данные гильдий.

2. Сообщения и активность

Для систем прогресса и статистики приложение считает сообщения пользователей и хранит агрегированную статистику активности по дням. Для голосовой статистики фиксируется продолжительность голосовых сессий.

3. AI-функции

При использовании AI-функций история соответствующего AI-канала может сохраняться для поддержания контекста ответов. История ограничивается внутренним размером, предусмотренным приложением.

4. Для чего используются данные

  • для сохранения и отображения игрового прогресса;
  • для работы экономики, питомцев, гильдий, заданий и рейтингов;
  • для расчёта статистики активности;
  • для работы AI-контекста в соответствующих функциях;
  • для технической работы приложения.

5. Хранение

Игровые данные сохраняются в хранилище приложения и периодически записываются на диск. Файл данных имеет резервную копию, создаваемую при сохранении.

6. Сторонние сервисы

Отдельные функции могут зависеть от Discord и сторонних сервисов, используемых приложением. При их использовании соответствующие данные могут обрабатываться такими сервисами в соответствии с их собственными условиями и политиками конфиденциальности.

7. Безопасность

Администрация принимает разумные технические меры для защиты данных, однако не может гарантировать абсолютную безопасность любой системы хранения или передачи данных.

8. Изменения политики

Политика может обновляться вместе с изменением функциональности Rip World. Актуальная редакция публикуется на этой странице.

9. Контакты

Запросы по вопросам конфиденциальности следует направлять через официальный канал поддержки проекта или контакт разработчика, указанный на сервере поддержки.

Эта страница описывает обработку данных именно в рамках текущего проекта Rip World и должна обновляться при изменении фактической архитектуры или сторонних интеграций.
